# ШколаМаркет — учебный frontend-проект

Многостраничный сайт интернет-магазина школьных товаров.
Выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Проект реализован без CSS-фреймворков. JavaScript используется минимально —
только для открытия модального окна заявки и базовой обработки формы.

## Ссылка на опубликованный проект

GitHub Pages: https://alisngol.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары, модальное окно заявки;
- `catalog.html` — каталог из шести товаров с блоком фильтров;
- `product.html` — карточка товара: изображение, описание, таблица характеристик;
- `order.html` — страница оформления заявки с развёрнутой формой;
- `contacts.html` — контактная информация и режим работы;
- `css/style.css` — единый файл стилей, разделённый на 22 блока;
- `js/main.js` — открытие модального окна и обработка отправки формы;
- `images/` — векторные изображения товаров в формате SVG;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML5 с семантической разметкой;
- CSS3: переменные, Flexbox, CSS Grid, позиционирование;
- методология БЭМ для именования классов;
- минимальный JavaScript для модального окна;
- Git и GitHub, публикация через GitHub Pages.

## Реализованные требования

### Семантика
`header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`.
На каждой странице один `main` и один `h1`.

### Навигация
- единое меню на всех пяти страницах;
- активный пункт выделен модификатором `site-nav__link--active`;
- якорные ссылки вида `index.html#popular`;
- хлебные крошки на внутренних страницах;
- плавная прокрутка и подсветка цели через `:target`.

### CSS-архитектура
- переменные в `:root`: цвета, шкала отступов, шкала размеров текста, скругления;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- подсветка ошибочных полей через атрибут `aria-invalid`;
- файл разделён на именованные блоки комментариями.

### Flexbox и Grid
- Flexbox: навигация, внутренняя структура карточек, группы кнопок;
- Grid: сетка товаров `repeat(auto-fill, minmax(220px, 1fr))`;
- Grid: раскладка каталога «фильтры + товары» через `grid-template-areas`;
- Grid: раскладка страницы заявки «форма + информация».

### Позиционирование
- `position: sticky` — шапка сайта и блок фильтров в каталоге;
- `position: relative` — карточка товара как контейнер;
- `position: absolute` — бейджи «Хит», «Новинка», «Скидка»;
- `position: fixed` — кнопка «Наверх»;
- `z-index` — порядок наложения шапки, бейджей и кнопки.

### Формы
- модальное окно `<dialog>` с формой быстрого заказа на главной;
- развёрнутая форма заявки на `order.html` с группировкой через `fieldset`;
- поля: имя, e-mail, телефон, дата, товар, количество, способ получения, комментарий, согласие;
- у каждого поля есть `label`, связанный через `for` и `id`;
- валидация через `required`, `minlength`, `pattern`, `type="email"`.

### Таблица
Характеристики товара на `product.html`: `caption`, `thead`, `tbody`,
заголовки строк и столбцов через `th` с атрибутом `scope`.

### БЭМ-блоки
`site-header`, `site-nav`, `breadcrumbs`, `hero`, `section`, `products-grid`,
`product-card`, `product`, `product-table`, `catalog-layout`, `catalog-filters`,
`filters-form`, `order-layout`, `order-dialog`, `order-form`, `button`,
`aside-info`, `success-message`, `scroll-top`, `site-footer`.

## Как проверить проект

1. Открыть ссылку GitHub Pages или файл `index.html` локально.
2. Проверить переходы по меню между всеми пятью страницами.
3. Проверить якорные ссылки «Преимущества» и «Популярные товары».
4. Нажать «Заказать» в карточке товара — откроется модальное окно,
   выбранный товар запишется в скрытое поле формы.
5. Отправить пустую форму — поля подсветятся красным.
6. Заполнить корректно (телефон в формате `+7 (900) 000-00-00`) — появится
   сообщение об успешной отправке.
7. Открыть `catalog.html` — проверить сетку из шести карточек и блок фильтров.
8. Открыть `product.html` — проверить таблицу характеристик и бейдж на изображении.
9. Открыть `order.html` — проверить форму заявки и кнопку очистки.
10. Пройти по странице клавишей `Tab` — у элементов появляется видимый фокус.

## Примечания к реализации

Фильтры в каталоге оформлены как статическая разметка: контрольная работа №1
выполняется на HTML и CSS, логика фильтрации относится к блоку JavaScript
и будет добавлена в контрольной работе №4.

Страница `product.html` одна и описывает конкретный товар. В реальном проекте
такие страницы генерирует backend, что выходит за рамки данной работы.
